# 校园活动展板生成 · 规格与自定义指南

本技能结合内置「源文件」生成印刷级校园活动展板（默认诗词大赛版）。
**源文件**指技能内 `assets/` 下的：`cleaned_bg.png`（无字山水底板）+ 小盒品牌VI + 3D布克IP。
所有**文字为矢量重绘**，放大到任何尺寸都锐利；背景为高质量放大（LANCZOS）。

## 一、默认文案（可直接改）
| 区块 | 内容 |
|---|---|
| 红印章 | 岐山教育 |
| 主标题 | 岐山县首届中小学诗词大赛 |
| 标语 | 凤鸣岐山  诗润童年 |

## 二、怎么改文字（两种方式）
**方式 A — 改脚本里的 CONFIG 块**（最直观）
打开 `scripts/build_poster.py`，顶部 `CONFIG = {...}` 里改对应字段，然后运行：
```
python3 scripts/build_poster.py
```

**方式 B — 用 JSON 覆盖（不改脚本，适合批量/分享）**
新建一个 `my.json`：
```json
{
  "title": "扶风县首届中小学诗词大赛",
  "seal_text": "扶风教育",
  "tagline": "凤鸣岐山  诗润童年",
  "organizers": [
    ["主办单位", "扶风县教育体育局"],
    ["承办单位", "北京小盒科技"],
    ["协办单位", "扶风县中心小学"]
  ],
  "location": "陕西 · 宝鸡 · 扶风",
  "date": "2026.11"
}
```
运行：
```
python3 scripts/build_poster.py --config my.json --out ./output
```
> 只写想改的字段即可，其余沿用默认。

## 三、可调参数（CONFIG 字段说明）
- `seal_text`：红印章文字。≤2 字单行；4 字自动两行（如「岐山/教育」）。
- `show_brand` / `show_activity_vi`：是否显示「小盒」橙标 / 「小盒校园活动」黑标。
- `show_ip`：是否显示左下角 3D布克 IP。
- `width/height/dpi`：画面尺寸，默认 9600×5400 @ 300DPI（81.3×45.7cm）。
- `ink/teal/gold/red`：配色（RGB），可整体换色。
- `export_pdf`：是否同时导出 300DPI 印刷 PDF（发给打印社用）。

## 四、输出文件
运行后在输出目录生成：
- `诗词大赛展板_9600x5400.png` — 主文件（高清位图）
- `诗词大赛展板_印刷源文件_300dpi.pdf` — **发给打印社用**（页面尺寸锁定、无损内嵌）
- `预览.jpg` — 快速预览

## 五、关于「放大不糊」
1. 文字是矢量重绘 → 任意尺寸锐利，绝不糊。
2. 背景山水来自 1080px 原图、已高质量放大到 9600px：
   - ≤ 81cm 宽印刷清晰锐利；
   - 放大到 1.2m/1.6m 大板时，因展板远观，**实际观看不觉得糊**（近看背景轻微柔化，属正常）。
3. 打印社请勿对 PDF 再次缩放/压缩，按 300DPI 原尺寸输出。

## 六、字体依赖（重要）
- **macOS**：用系统自带「宋体 Songti」（标题书卷气，非楷书）+「黑体 STHeiti」（标签）。
- **Windows**：脚本自动改用 `simsun.ttc`（宋体）/ `msyh.ttc`（雅黑），无需额外安装。
- 如缺字体，脚本会报错提示。Linux 需自行安装中文字体（如 Noto Sans CJK）。

## 七、品牌合规
按小盒校园活动 VI 规范：浅色背景用「小盒校园活动」**黑版**；所有物料应露出小盒 Logo + 布克/小象 IP。本技能已默认带齐，请勿删除顶部品牌元素。
