# 小盒校园活动展板生成器（可分享版）

本技能把「小盒精品校园活动物料库」消化成一个**自包含、可分发**的展板生成能力：
内置源文件（无字山水底板 + 小盒品牌VI + 3D布克IP），用脚本把文字**矢量重绘**后合成印刷级展板。
伙伴拿到本技能，装进自己的 WorkBuddy，发一句「帮我做张诗词大赛展板，县名改成 XX」就能出图。

## 何时使用
- 用户要**制作/修改校园活动展板、海报、主视觉**（尤其诗词大赛、语文类活动）。
- 用户**发来一张图片**，要求「照这个改文字 / 换个县 / 调配色再做一张」。
- 用户要**印刷级文件**发给打印社（需 PDF + 不糊）。

## 源文件（已随技能分发，位于 `assets/`）
- `assets/cleaned_bg.png` — 无字山水底板（背景，重绘文字即复用）
- `assets/brand-vi/小盒标志-01.png` — 小盒品牌橙标
- `assets/activity-vi/小盒校园活动-黑.png` — 小盒校园活动VI（浅底黑字，合规用）
- `assets/ip/3D布克-古装站姿1.png` — 3D布克IP（古装书生·毛笔书卷）

## 工作流（拿到"制作图片"诉求后）
1. **确认文案**：从用户消息或其所发图片中提取要改的字段（县名/单位/标语/日期等）。
   - 若用户发图含新文字，用 ViewImage 先读图确认原文，再按用户要求替换。
2. **改配置**（二选一）：
   - **A. 改脚本 CONFIG**：编辑 `scripts/build_poster.py` 顶部 `CONFIG` 块（标题/标语/主办承办协办/地点日期/红印章/配色）。
   - **B. 写 JSON 覆盖**（推荐，不动脚本）：把要改的字段写成 `my.json`，
     运行 `python3 scripts/build_poster.py --config my.json --out <输出目录>`。
     只写要改的字段，其余沿用默认（详见 `references/poster-spec.md`）。
3. **运行生成**：脚本输出 PNG（9600×5400）+ 300DPI 印刷 PDF + 预览 jpg。
4. **核验**：用 ViewImage 看 `预览.jpg`（或裁出标题/印章区域全分辨率核验）确认文字无误、无裁切、品牌元素齐全。
5. **交付**：用 present_files 给出 PNG 与 PDF；提醒打印社用 PDF、勿缩放。

## 关键设计（保证"放大不糊"）
- 所有文字走 **PIL 字体矢量渲染**，放大永远锐利。
- 背景 `cleaned_bg.png` 由 1080px 原图 LANCZOS 高质量放大，≤81cm 宽印刷清晰；更大展板因远观也不显糊。
- 字体跨平台：macOS 用 Songti+STHeiti；Windows 自动改用 simsun/msyh（详见 spec）。

## 品牌合规（出图前必查）
- 顶部必须保留「小盒」橙标 + 「小盒校园活动」黑标；左下角保留 3D布克 IP。
- 浅底用黑版VI（已内置）。勿删品牌元素。
